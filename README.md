# タスク管理

ブラウザだけで動く、シンプルなタスク管理ツールです。
HTML / CSS / JavaScript のみで作られており、サーバーやビルド作業、外部ライブラリは必要ありません。

## 機能

- **タスクの追加**：タスク名と期限（任意）を入力して追加できます。
- **完了 / 未完了の切り替え**：チェックボックスで切り替えます。完了したタスクには取り消し線が付きます。
- **期限の表示**：期限までの残り日数を表示します。
  - 期限切れ：「10/26（月） ・ 2日超過」（赤で強調）
  - 当日：「10/28（水） ・ 今日まで」（オレンジで強調）
  - 3日以内：「あと◯日」（オレンジの文字）
  - 期限なし：「期限なし」
- **絞り込み**：「すべて／未完了／今日まで／期限切れ／完了」の切り替えに加え、キーワードでも絞り込めます。各ボタンには該当する件数が表示されます。
- **並び順**：未完了のタスクが先に並び、その中では期限の近い順（期限なしは最後）になります。
- **削除**：タスクごとの「×」ボタンで削除できます。「完了済みをすべて削除」で、完了したタスクをまとめて消すこともできます（確認ダイアログが出ます）。
- **自動保存**：データはブラウザの `localStorage` に保存されるため、ページを閉じても残ります。
- **その他**：ダークモードとスマートフォン幅の画面に対応しています。別のタブで変更した内容も自動で反映されます。

## 使い方

1. このリポジトリをダウンロード（またはクローン）します。
2. `index.html` をブラウザで開きます（ダブルクリックで開けます）。

ローカルサーバーで動かしたい場合は、例えば次のコマンドを実行してから `http://localhost:8000` を開いてください。

```bash
python3 -m http.server 8000
```

GitHub Pages などの静的ホスティングにそのまま置いても動作します。

## ファイル構成

```
.
├── index.html   # 画面の構造
├── style.css    # 見た目（ライト / ダークモード、レスポンシブ対応）

```

## データの保存について

- タスクは、ブラウザの `localStorage` にキー `task-manager.tasks.v1` で保存されます。
- 保存先は **使っているブラウザと端末ごと** です。別のブラウザや端末とは共有されません。
- ブラウザの閲覧データ（サイトデータ）を消去すると、タスクも消えます。
- プライベートブラウズなどで保存できない環境では、そのタブを開いている間だけ動作します。

## 動作環境

Chrome、Edge、Firefox、Safari など、最新版のモダンブラウザで動作します。
