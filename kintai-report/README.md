# 勤怠分析レポート（KintaiReport）

勤怠Excel（「勤怠」シート）を読み込み、**部署別の月次累計勤怠分析レポート**を **A4横のPDF** で出力する Windows / Visual Studio 向けのコンソールツールです。

- 年度開始月（既定 4月）から指定月までの **月次＋累計** を部署別に集計
- 所定時間外の **普通残業／深夜残業（22:00〜翌6:00）／休日出勤** を自動計算
- **時間外時間 上位20名**、**出勤日数 下位20名**、**未承認者一覧**、**部署別出勤率ヒートマップ** を出力
- 休憩ルール・除外者・入社日／退職日・部署の並び順・所定時間などは **設定ファイル（YAML）** で変更可能

> 同梱のサンプルデータ・サンプルPDFの氏名はすべて架空（「見本 花子」「仮名 一郎」など）で、実在の人物とは関係ありません。

---

## 1. 必要環境

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / 11（Linux・macOS でも動作） |
| 開発環境 | Visual Studio 2022（17.8 以降）「.NET デスクトップ開発」ワークロード |
| ランタイム | .NET 8 |
| 使用ライブラリ（NuGet） | ClosedXML（Excel読込）、QuestPDF（PDF生成）、YamlDotNet（設定ファイル） |

NuGet パッケージはビルド時に自動で復元されます。

## 2. フォルダ構成

```
kintai-report/
├─ KintaiReport.sln                ← Visual Studio で開くソリューション
├─ src/KintaiReport/               ← 本体（コンソールアプリ）
│   ├─ settings.yaml               ← 設定ファイル（ビルド時に exe と同じフォルダへコピー）
│   ├─ Program.cs                  ← 起動・引数処理
│   ├─ Config/                     ← 設定ファイルの読み込み
│   ├─ Excel/AttendanceReader.cs   ← 勤怠Excelの読み込み
│   ├─ Calc/                       ← 勤務時間計算・集計
│   └─ Pdf/ReportDocument.cs       ← PDFレイアウト
├─ tools/SampleDataGenerator/      ← ダミーの勤怠Excelを作るツール
├─ tests/KintaiReport.Tests/       ← 単体テスト（xUnit）
└─ sample/
    ├─ 勤怠サンプル.xlsx            ← ダミーデータ（107名×2026年4〜9月）
    └─ 勤怠分析レポート_サンプル.pdf ← 上記から出力したレポート
```

## 3. 使い方

### Visual Studio で実行

1. `KintaiReport.sln` を開く
2. スタートアッププロジェクトを **KintaiReport** にする
3. 起動プロファイル「サンプルデータで実行」のまま **F5**
   → `sample/勤怠分析レポート_サンプル.pdf` が作成されます

自分のExcelで試すときは、プロジェクトのプロパティ →「デバッグ」→「起動プロファイル」のコマンドライン引数を書き換えてください。

### exe として配布・実行

```bash
dotnet publish src/KintaiReport -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o publish
```

`publish` フォルダ（`KintaiReport.exe`・`settings.yaml`・PDF描画用の DLL 類）を **フォルダごと** 配布して使います（.NET 未インストールのPCでも動作）。

- **ドラッグ＆ドロップ**：勤怠Excelを `KintaiReport.exe` にドロップすると、Excelと同じフォルダに `勤怠分析レポート_yyyyMM.pdf` が出力されます。
- **コマンドライン**：

```bash
KintaiReport.exe 勤怠.xlsx
```

```bash
KintaiReport.exe 勤怠.xlsx --month 2026-06 -o 6月度レポート.pdf -c D:\設定\settings.yaml
```

| オプション | 説明 |
|---|---|
| `-m`, `--month yyyy-MM` | 累計の最終月。年度開始月からこの月までを集計（省略時はデータ内の最終月） |
| `-o`, `--output パス` | 出力PDFのパス（省略時は Excel と同じフォルダ） |
| `-c`, `--config パス` | 設定ファイル（省略時は exe と同じフォルダの `settings.yaml`） |
| `-h`, `--help` | ヘルプ表示 |

実行すると、読み込み行数・対象期間のほか、打刻漏れ・重複行・在籍期間外の出勤などの「注意」がコンソールに表示されます。

## 4. 入力Excelの形式

「勤怠」シートの1行目を見出しとし、**1人1日1行** で記録されている形式を想定しています。列の順番は自由で、見出し名で列を探します（見出し名は設定ファイルで変更可）。

| 見出し（既定） | 必須 | 内容 | 例 |
|---|---|---|---|
| 社員番号 | ○ | 社員を一意に識別するID | E0001 |
| 氏名 | ○ | 氏名 | 見本 花子 |
| 部署 | ○ | 所属部署 | 店舗課 |
| 日付 | ○ | 勤務日（日付型または `2026/4/1` 形式の文字列） | 2026/04/01 |
| カレンダー | ○ | 「平日」なら所定出勤日。それ以外（土曜・日曜・祝日・会社休日など）は休日 | 平日 |
| 出勤時刻 | ○ | 時刻型・`9:00` 形式の文字列のどちらでも可 | 8:52 |
| 退勤時刻 | ○ | 同上。翌日にまたがる場合は `25:30` のように書くか、出勤より小さい時刻（`1:30`）を入れると翌日とみなします | 19:10 |
| 休憩(分) | ― | 休憩の分数（`60`）または時間（`1:00`）。空欄・列なしなら休憩ルールで計算 | 60 |
| 承認状況 | ○ | 「承認済」以外は未承認として一覧に掲載 | 承認済 |

上記以外の列（曜日・備考など）は無視されます。休日で打刻のない行・欠勤日の行はあっても無くても構いません。

## 5. 計算ルール

### 所定時間・残業・深夜

| 区分 | 定義 |
|---|---|
| 所定出勤日 | カレンダー欄が「平日」の日（`input.workdayCalendarValues` で変更可） |
| 所定時間 | 9:00〜18:00（**店舗課のみ 11:00〜20:00**） |
| 普通残業 | 所定出勤日に、所定時間の **前後** に働いた時間（深夜帯を除く） |
| 深夜残業 | 所定時間外のうち **22:00〜翌6:00** に働いた時間（平日・休日とも） |
| 休日出勤 | 所定出勤日以外に働いた時間（深夜帯を除く） |
| 時間外合計 | 普通残業 ＋ 深夜残業 ＋ 休日出勤（重複なし） |

- 休憩は Excel の休憩列を優先し、空欄なら **休憩ルール** で決めます（既定：拘束6時間超→45分、8時間超→60分）。
- 休憩は所定時間内に取ったものとして、**所定内の時間から先に** 差し引きます（所定内の時間より長い休憩の余りは残業から差し引き）。
- 例：総務課 8:50〜23:30（休憩60分）→ 普通残業 4:10（8:50〜9:00、18:00〜22:00）、深夜残業 1:30
- 例：店舗課 11:00〜23:00 → 普通残業 2:00、深夜残業 1:00
- 例：土曜 13:00〜23:00（休憩60分）→ 休日出勤 8:00、深夜残業 1:00
- 1日ごとの各時間を N 分単位で切り捨てる丸めも設定できます（既定は丸めなし）。

### 出勤日数・出勤率

| 項目 | 定義 |
|---|---|
| 所定日数 | 在籍期間内で、カレンダーが「平日」の日数（会社全体のカレンダーから算出） |
| 出勤日数 | 打刻のある日数（所定出勤日の出勤 ＋ 休日出勤） |
| 出勤率 | 所定出勤日のうち出勤した日数 ÷ 所定日数 |

- 在籍期間は `employees` の入社日・退職日を使います。入社日の設定がない社員は、Excel 上で最初に記録がある日を入社日とみなします。
- 有給休暇などで打刻がない日は「出勤していない日」として数えます（レポート上は「欠勤等日数」）。

### 集計期間

`report.fiscalYearStartMonth`（既定 4月）から、`--month` で指定した月（省略時はデータの最終月）までを累計します。データが月の途中までしかない場合は、データの最終日までを対象にします。

### 部署

- 各月の部署別集計は **その月の所属部署** で計上します（期間途中の異動に対応）。
- ランキング・部署別明細には **最終所属部署** を表示します。

## 6. 設定ファイル（settings.yaml）

`src/KintaiReport/settings.yaml`（配布時は exe と同じフォルダ）をメモ帳などで編集します。UTF-8 で保存してください。主な項目：

```yaml
departments:
  order: [総務課, 人事課, 経理課, 営業1課, 営業2課, 開発課, 店舗課]   # 表示順

schedule:
  default: { start: "09:00", end: "18:00" }
  byDepartment:
    店舗課: { start: "11:00", end: "20:00" }

lateNight: { start: "22:00", end: "06:00" }

break:
  useExcelBreakColumn: true
  rules:
    - { overMinutes: 360, breakMinutes: 45 }   # 拘束6時間超 → 45分
    - { overMinutes: 480, breakMinutes: 60 }   # 拘束8時間超 → 60分

excludedEmployees: [E9001, E9002]   # 集計から除外（役員・テストIDなど）

employees:
  - { id: E0108, hireDate: 2026-06-01 }
  - { id: E0042, retireDate: 2026-07-31 }
```

| キー | 内容 |
|---|---|
| `input.sheetName` / `input.headerRow` | 読み込むシート名・見出し行 |
| `input.columns.*` | 各列の見出し名 |
| `input.workdayCalendarValues` | 所定出勤日とみなすカレンダー欄の値 |
| `input.approvedValues` | 承認済みとみなす承認欄の値 |
| `report.title` / `report.companyName` | PDFのタイトル・会社名 |
| `report.fiscalYearStartMonth` | 累計の起点月 |
| `report.topOvertimeCount` / `report.bottomAttendanceCount` | ランキングの人数（既定 20） |
| `report.showDepartmentDetails` | 部署別の社員明細ページを出すか |
| `report.font.families` / `report.font.file` | 使用フォント（上から順に使用）／フォントファイル直接指定 |
| `departments.order` | 部署の並び順（未記載の部署は末尾に名前順） |
| `schedule.default` / `schedule.byDepartment` | 所定時間（部署別に上書き可） |
| `lateNight` | 深夜時間帯 |
| `break.useExcelBreakColumn` / `break.rules` | 休憩の決め方 |
| `rounding.overtimeUnitMinutes` | 1日ごとの残業等の切り捨て単位（分） |
| `excludedEmployees` | 除外する社員番号 |
| `employees` | 社員ごとの入社日・退職日 |
| `heatmap.minRate` / `heatmap.maxRate` | ヒートマップの色の範囲 |

書式の誤りや存在しない列名があると、どこが違うかをメッセージで表示して終了します。

## 7. レポートの構成（A4横）

| ページ | 内容 |
|---|---|
| 概要 | 時間外合計・1人あたり時間外・出勤率・未承認件数のサマリーと、部署別サマリー表 |
| 部署別 月次推移 | 部署×月の時間外時間・出勤日数（当月／年度累計の2段表示） |
| 部署別 出勤率ヒートマップ | 部署×月の出勤率。色が濃いほど出勤率が低い（各セルに％と日数を併記） |
| 時間外時間 上位20名 | 普通・深夜・休日の内訳、月平均、最大月、月別推移の棒グラフ |
| 出勤日数 下位20名 | 出勤日数・所定日数・欠勤等日数・出勤率・入社日／退職日 |
| 未承認者一覧 | 部署・社員ごとの未承認件数と対象日 |
| 部署別明細 | 部署ごとに社員別の月別時間外・累計・出勤日数・出勤率 |

出力例は `sample/勤怠分析レポート_サンプル.pdf` を参照してください。

## 8. サンプルデータの作り直し・テスト

```bash
dotnet run --project tools/SampleDataGenerator -- sample/勤怠サンプル.xlsx
```

```bash
dotnet run --project src/KintaiReport -- sample/勤怠サンプル.xlsx -o sample/勤怠分析レポート_サンプル.pdf
```

```bash
dotnet test
```

Visual Studio では「テスト」→「テスト エクスプローラー」から実行できます。テストでは残業・深夜・休日・休憩・日付またぎ・店舗課の所定時間・Excelの各種時刻形式の読み込み・サンプルデータでの集計（除外者、入社日、部署順、ランキング）を確認しています。

- Excel を開いたままでも読み込めますが、保存前の変更は反映されません。
